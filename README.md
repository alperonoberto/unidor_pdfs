# 📚 Unidor y compresor de PDFs
Una herramienta práctica, rápida y eficiente diseñada para simplificar la gestión de tus documentos digitales. Olvídate de complicados procesos de configuración o instalaciones engorrosas; descarga el ejecutable y unifica múltiples archivos PDF en un solo documento de forma limpia y ordenada.
## ✨ Características Principales
- **Sin Instalación:** Aplicación portátil lista para ejecutar desde el primer momento.
- **Fácil y Rápido:** Combina tus documentos en cuestión de segundos con solo unos pocos clics.
- **Interfaz Intuitiva:** Diseñada para ofrecer una experiencia de usuario fluida y sin distracciones.
## 🚀 ¿Cómo usarlo?
1. Dirígete a la sección de [Releases](https://github.com/alperonoberto/unidor_pdfs/releases) de este repositorio.
2. Descarga el archivo ejecutable correspondiente a tu sistema operativo y a la última versión disponible.
3. Ejecuta el archivo descargado para comenzar a unificar tus PDFs de forma inmediata.
## 🛠️ Tecnologías Utilizadas
Este proyecto está construido con tecnologías modernas para garantizar un rendimiento óptimo y una gran compatibilidad en entornos de escritorio.
## 🤝 Contribuciones
¡Las contribuciones son siempre bienvenidas! Si tienes ideas para mejorar la herramienta, encuentras algún error o quieres proponer nuevas funcionalidades, siéntete libre de abrir un Issue o enviar un Pull Request.

>Las versiones oficiales para Windows y Linux x86-64 comprueban si hay actualizaciones al iniciar. Si hay una nueva versión, puedes confirmar su descarga e instalación desde el aviso; la aplicación se reiniciará automáticamente. La instalación requiere permisos de escritura en la carpeta donde está el ejecutable.
